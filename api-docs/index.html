ReaDex — Source Adapter Spec

A practical reference for building an HTTP backend ReaDex can read.

What this is

ReaDex is a personal reader client. At first-run the user supplies a single base URL; the app routes every outbound call through that URL. These pages describe the HTTP contract an endpoint must satisfy so ReaDex can render its catalog, title detail, chapter feed, pages and covers.

The demo source at https://lajennylove.github.io/readex/ is the canonical implementation. Everything below is what that source serves, documented so you can build your own.

Who this is for

A backend developer who speaks HTTP + JSON and wants to stand up an endpoint that ReaDex will treat as a valid source. No prior familiarity with any specific upstream catalog required.

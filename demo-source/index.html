ReaDex demo content source

This static site is a placeholder content source for the ReaDex reader app. It exists so Apple App Review (and anyone else exercising the app for the first time) has a working URL to paste into the first-run Setup screen.

What it serves

  • Three invented titles with two chapters each (four placeholder pages per chapter).
  • Covers and pages are plain geometric SVGs — no third-party content, no copyrighted material.
  • Authors, titles, and descriptions are all invented placeholders.

How to use it in ReaDex

  1. Open ReaDex. On first launch, you’ll see the Setup screen.
  2. Paste the URL to this site’s /api directory into the source URL field.
  3. Give the source a name (any label works — “Demo” is fine).
  4. Save. Browse the catalog, open a title, download a chapter, read it.

Endpoints

Request shape mirrors the generic HTTP adapter the app ships with:

  • GET /api/manga — catalog list.
  • GET /api/manga/{id} — title detail.
  • GET /api/manga/{id}/feed — chapter list for a title.
  • GET /api/at-home/server/{chapterId} — page server info for a chapter.
  • GET /covers/{titleId}/{file} — cover images.
  • GET /data/{hash}/{file} and /data-saver/{hash}/{file} — page images.

Rebuild

python3 build.py in demo-source/. Idempotent — overwrites JSON and SVG. No external dependencies.

Not for public catalog browsing. Hosted here only so App Store review has a known-good URL to point the app at.

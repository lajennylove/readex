Personal reader client

A reader for a content source
you provide.

ReaDex is a transport-and-render tool. You supply the source URL; the app browses, downloads, and reads what it returns. No catalog, no accounts, no telemetry — like a browser, for a single API.

Three things, done well

A short list of what the app actually promises.

1

On-device only

No accounts. No analytics. No crash SDKs. Your library, your chapters, your downloads — all on your phone, nowhere else.

2

Content-source agnostic

One URL goes in Settings. You choose it. Point it at your own backend, a static JSON mirror, or any service that implements the protocol.

3

Open protocol

The source API is a short, documented contract. Read the spec and swap the backend whenever you like.

Build your own source

Any backend that implements the ReaDex protocol can plug in. Spec, endpoint shapes, and JSON schemas live on one page.
